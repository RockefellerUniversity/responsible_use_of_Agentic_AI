# Responsible Use of Agentic AI

<br>

This course is for researchers who write code and want to use agentic AI coding assistants, such as Claude Code and Codex, responsibly in their analysis. These tools do more than chat: they read your files, run commands and write code in your projects.

The course starts with how large language models (LLMs) work and what Rockefeller's AI policy allows. It then covers what the model sees when you send a query: the context window, instruction files such as CLAUDE.md and AGENTS.md, and memory. From there it moves on to extending an assistant with skills, connectors (MCP servers) and plugins, including the subagents and hooks inside them, and the security risks each one brings. The final sessions cover where AI helps and fails in bioinformatics, adversarial review of AI-written work, and a workflow built on planning, reproducibility, checkpoints and controls on what the agent is allowed to do. Throughout, you remain the final check on everything it produces.

Course material and exercises are available to view as rendered HTML at https://rockefelleruniversity.github.io/responsible_use_of_Agentic_AI/.
All material is available to download under GPL v2 license.
